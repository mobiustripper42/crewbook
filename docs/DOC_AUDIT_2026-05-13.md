`PROJECT_PLAN.md` "Key Decisions" table (lines 213–225) still uses the pre-namespacing scheme — same product decisions renumbered DEC-001..DEC-012.

| Slot | `DECISIONS.md` says | `PROJECT_PLAN.md` says |
|------|---------------------|------------------------|
| DEC-001 | Supabase-direct instead of Express API | Supabase for DB |
| DEC-002 | Next.js 14+ App Router | Xola stays as booking |
| DEC-003 | Single profiles table | Anthropic API for agents |
| DEC-004 | shadcn/ui | Magic links |
